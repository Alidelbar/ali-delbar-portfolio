# Ali Delbar — Product Portfolio

Final static portfolio site.

## Run locally
Open `index.html`.

## Publish with GitHub Pages
1. Create a public repository, e.g. `ali-delbar-portfolio`.
2. Upload all files from this folder to the repository root.
3. In GitHub: Settings → Pages.
4. Source: `Deploy from a branch`.
5. Branch: `main`, folder: `/ (root)`.
6. Save. GitHub will provide the public URL.

The site includes:
- Persian / English switch
- responsive layout
- product case studies
- motion and micro-interactions
- downloadable resume
- LinkedIn and email contact
- favicon and social metadata
